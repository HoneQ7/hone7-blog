字符串题表面上是匹配，实际上经常考“如何复用已经比较过的信息”。KMP、Z 函数和字符串哈希都在解决这个问题，只是抽象角度不同。

## KMP：前缀与后缀

KMP 的 `pi[i]` 表示 `s[0..i]` 的最长相等真前后缀长度。它的价值在于失配时不用回到模式串开头，而是跳到一个仍然可能匹配的位置。

```cpp
vector<int> prefix_function(const string& s) {
    int n = (int)s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j]) {
            j = pi[j - 1];
        }
        if (s[i] == s[j]) {
            j++;
        }
        pi[i] = j;
    }
    return pi;
}
```

用 KMP 做文本匹配时，可以拼接 `pattern + '#' + text`，然后找 `pi[i] == pattern.size()` 的位置。分隔符要保证不会出现在原字符串中。

## Z 函数：从当前位置开始的公共前缀

Z 函数的 `z[i]` 表示 `s[i..]` 和整个字符串 `s` 的最长公共前缀长度。它适合处理“每个后缀和原串前缀比较”的问题，例如模式串匹配、前缀出现次数统计。

我理解 Z 函数时会重点看 `[l, r]` 区间：它记录当前最靠右的匹配段。落在区间内的位置可以复用之前算过的值，只有超过右端点时才继续暴力扩展。

## 字符串哈希：把比较变成 O(1)

哈希适合大量子串相等判断。典型写法是预处理前缀哈希和幂：

```cpp
using ull = unsigned long long;

vector<ull> h(n + 1), p(n + 1);
p[0] = 1;
for (int i = 0; i < n; i++) {
    h[i + 1] = h[i] * base + s[i];
    p[i + 1] = p[i] * base;
}

auto get_hash = [&](int l, int r) {
    return h[r] - h[l] * p[r - l];
};
```

这里区间是左闭右开 `[l, r)`，这样和 C++ 的很多字符串 API 保持一致。实际比赛中要注意哈希冲突，必要时使用双哈希。

## 选择算法的经验

- 单模式串匹配：KMP 或 Z 函数都可以。
- 判断很多子串是否相等：字符串哈希更方便。
- 需要严格无冲突：优先考虑后缀数组、后缀自动机或直接用确定性算法。
- 题目围绕前缀、周期、border：优先想 KMP 的前缀函数。

字符串算法的模板不算长，但变量含义很密。后续我会给每个模板配一个小样例，把数组每一位的值手算出来，减少只会背代码的问题。
