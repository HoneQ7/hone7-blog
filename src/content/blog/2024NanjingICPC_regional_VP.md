## B. Birthday Gift
### 题目大意
输入一个字符串包含 `0,1,2` ,你可以进行以下两种操作：1、删除`00`或`11`字序列 2、将任意一个`2`改成`0`或`1`。
题目要求你输出经过若干次操作之后能获得的最短的序列的长度
### 赛时思路（错误❌）
赛时我发现这道题有点类似于DP,因为每次删除字符都可以视作一个字问题，并且题目存在`2`这样的特殊功能的字符，所以需要满足全局最优解，这也符合DP的思想，但是我对于是否是无后效性并无法准确的判断，导致我一时间找不到转移方程而卡住
### 题解思路（正确✅）
(这个思路十分的巧妙我在此之前完全没有想到还有这样的解法) 首先将偶数下标的字符取反：`1` 变成 `0` ; `0` 变成 `1` ; `2` 不变。
然后，题目就从删除相同的 `11` 或 `00` 变成 删除不同的 `10` 或者 `01` 而 `11` 或 `00` 则被保留，那么由此我们不难发现，字符串里只要还同时存在 `1` 或 `0` 则一定会出现相邻不同的配对，因此可以一直进行删除操作直至只剩单一字符为止。
#### 对于 `2` 的处理
由于我们知道 `2` 最终都会被改称 `0` 或 `1`，而由于题目的要求是让最终的长度尽可能小，因此，需要把2都改成数量较少的那一边
因此公式如下：
```C++
if(cnt2<=d) ans=d-cnt2;//d=abs(cnt1-cnt0)
else ans=(cnt2-d)%2;
```
综上，我们就可以而得出答案ans
*时间复杂度：`O(n)`*
